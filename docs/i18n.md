# 多语言 (i18n)

FuickJS 的国际化能力在 **JS 渲染层** 完成：文案在生成 DSL **之前** 通过 `t(key)` 解析为最终字符串，Flutter 侧 Parser 无需感知语言。该设计同时适用于原生 FuickJS 应用与 Taro 适配项目，且不依赖任何第三方 i18n 库。

```
React 组件 t('home.title')
  → i18n 查表 + 插值 + 复数
  → FuickNode.toDsl()（已是目标语言文案）
  → Flutter Widget
```

## 核心概念

| 概念 | 说明 |
|------|------|
| `i18n` | 全局唯一实例，管理资源、当前语言、订阅。 |
| `t(key, params?, options?)` | 翻译函数，绑定到 `i18n` 实例。 |
| `useTranslation()` | React hook，语言切换时自动重渲染组件。 |
| `useLocale()` | React hook，返回 `[locale, setLocale]`。 |
| `LOCALE_CHANGED_EVENT` | 语言变更时通过 `NativeEvent` 广播给 Native 侧的事件名（`'localeChanged'`）。 |

- **locale 归一化**：大小写不敏感、`_` 与 `-` 等价。`zh_CN`、`zh-CN`、`zh-cn` 视为同一语言。
- **回退链**：当前语言（精确）→ 当前语言主码（如 `zh-cn` → `zh`）→ `fallbackLocale` → `defaultValue` → key 本身。

## 快速开始

### 1. 配置资源（App 入口同步调用）

```typescript
import { i18n } from 'fuickjs';

i18n.configure({
  fallbackLocale: 'en',
  resources: {
    en: {
      home: { title: 'Home', greeting: 'Hello, {name}!' },
      cart: { items: { zero: 'No items', one: '{count} item', other: '{count} items' } },
    },
    'zh-CN': {
      home: { title: '首页', greeting: '你好，{name}！' },
      cart: { items: { other: '{count} 件商品' } },
    },
  },
});
```

### 2. 推断初始语言（异步，可选但推荐）

```typescript
// 优先级：持久化偏好 → 系统语言(DeviceInfo) → 已配置 locale/fallback
await i18n.init();
```

`init()` 依赖 `DeviceInfo` 与 `LocalStorage` 原生服务，故为异步；放在首页渲染前 `await` 即可。

### 3. 组件内使用

```tsx
import { useTranslation } from 'fuickjs';

export function Home() {
  const { t, locale, setLocale } = useTranslation();

  return (
    <Container>
      <Text text={t('home.title')} />
      <Text text={t('home.greeting', { name: 'Tom' })} />
      <Text text={t('cart.items', { count: 3 }, { count: 3 })} />
      <Button text={`Lang: ${locale}`} onTap={() => setLocale(locale === 'en' ? 'zh-CN' : 'en')} />
    </Container>
  );
}
```

切换语言后，所有使用 `useTranslation()` / `useLocale()` 的组件会自动重渲染。

## API

### `i18n.configure(options)`

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `resources` | `Record<string, TranslationResources>` | — | 语言 → 资源树，支持嵌套与复数对象。 |
| `locale` | `string` | — | 初始语言；不传则由 `init()` 推断。 |
| `fallbackLocale` | `string` | `'en'` | 兜底语言。 |
| `persist` | `boolean` | `true` | 是否把用户选择持久化到 LocalStorage。 |
| `persistKey` | `string` | `'fuickjs.locale'` | 持久化存储 key。 |
| `missingKeyHandler` | `(locale, key) => void` | — | 缺失 key 回调，便于上报。 |

可重复调用，资源会**深合并累积**。

### 其他方法

```typescript
i18n.addResources(locale, resources);   // 追加/合并某语言资源（懒加载场景）
i18n.getLocale();                        // 当前语言（归一化）
i18n.getAvailableLocales();              // 已注册语言列表
i18n.hasLocale(locale);                  // 是否有该语言资源
i18n.setLocale(locale);                  // 切换语言（持久化 + 广播 + 重渲染）
i18n.subscribe(listener);                // 订阅变更，返回取消函数（hook 内部使用）
i18n.init();                             // 推断初始语言（异步）
```

### `t(key, params?, options?)`

- `params`：`{ name }` → 替换模板里的 `{name}`。
- `options.count`：配合复数对象 `{ zero, one, other }` 选择类别（`count===0→zero`、`===1→one`、其余→`other`，缺失则回退 `other`）。
- `options.defaultValue`：key 缺失时的兜底文案。
- `options.locale`：本次翻译临时指定语言。

> 也支持把 `count` 直接放进 `params`：`t('cart.items', { count: 3 })` 等价于显式传 `options.count`。

## 与 Native 联动

切换语言时会通过 `NativeEvent.emit('localeChanged', { locale })` 广播给 Flutter 侧，宿主 App 可据此同步 `MaterialApp.locale` 或刷新原生 UI：

```dart
final eventService = controller.getService<NativeEventService>();
eventService?.on('localeChanged', (data) {
  final locale = (data as Map)['locale'] as String;
  // 同步宿主 App 语言…
});
```

> 系统语言仍可通过 `DeviceInfo.getDeviceInfo().locale` 获取；i18n 的「当前生效语言」与「系统语言」是两个独立概念。

## Taro 适配

Taro 项目通过 `@tarojs/taro-fuickjs` 直接复用同一套能力：

```typescript
import Taro, { useTranslation, configureI18n, initI18n, setLocale } from '@tarojs/taro';

configureI18n({ resources: { en: {...}, 'zh-CN': {...} }, fallbackLocale: 'en' });
await initI18n();

// 组件内
const { t } = useTranslation();
```

Taro 侧导出：`configureI18n` / `initI18n` / `getLocale` / `setLocale` / `getAvailableLocales` / `addI18nResources` / `t` / `useTranslation` / `useLocale`。

> `getSystemInfo().language` 仍返回**系统设备语言**（语义不变）；应用当前语言请用 `getLocale()`。
